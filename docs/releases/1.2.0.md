# Scoped Properties 1.2.0

Released 2026-11-15. Requires Obsidian 1.7.2 or later.

## Value-scoped filtering

Right-click any value row, including `(empty)`, and choose **Filter notes by this value**. The tree is reduced to notes that contain that value, and every other property is re-aggregated within the subset. The filtered property is hidden while the filter is active.

The filter bar under the toolbar shows the condition and the number of matching notes. Filters are live and session-only: metadata edits update the subset immediately, and reopening the view or reloading Obsidian returns to the whole vault.

Search, sorting, expand/collapse, saved views, copied note links, and bulk value edits operate on the filtered subset. **Open in Search** and **Copy search query** still run vault-wide queries.

## Fixes and documentation

- Bulk-edit copy now states that edits cover the notes listed in the preview, and an active filter narrows that preview.
- Focus returns to the filter bar's **Clear** button after applying a filter.
- Singular/plural filter counts, the empty state when notes match but no other properties exist, and coarse-pointer sizing were corrected.
- The user guide, README, bulk-editing guide, and changelog document scoped filtering and its interaction with edits and Search.

## Installation

Copy `main.js`, `manifest.json`, and `styles.css` into `<YourVault>/.obsidian/plugins/scoped-properties/`, then reload Obsidian and enable **Scoped Properties**. The core Search plugin is needed only for **Open in Search**.
