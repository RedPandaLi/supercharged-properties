# Supercharged Properties 1.0.1

Released 2026-11-14.

This maintenance release removes the plugin's use of an undocumented Obsidian API.

## Changed

- **Removed property type icons.** Property rows no longer show an icon based on Obsidian's configured property type.
- **Removed `metadataTypeManager` access.** The plugin no longer reads or listens to Obsidian's internal metadata type manager, so it no longer depends on an API that Obsidian does not commit to supporting.
- The plugin description no longer claims type icons.

Everything else is unchanged: the property tree, typed values, search, property scopes, saved views, sorting, pinning, hiding, and native Search actions all work as before. Value kinds such as `number`, `boolean`, and `empty` are still shown on value rows.

## Installation

1. Open **Settings → Community plugins → Browse** and install **Supercharged Properties** if it is listed.
2. To install manually, copy `main.js`, `manifest.json`, and `styles.css` into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then enable the plugin.

Requires Obsidian 1.7.2 or later. The core Search plugin is needed only for **Open in Search**.
