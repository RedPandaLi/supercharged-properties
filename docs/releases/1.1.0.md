# Supercharged Properties 1.1.0

Released 2026-11-14. Requires Obsidian 1.7.2 or later.

## Bulk value editing

Right-click a value row to rename it across matching notes, merge it into an existing value, convert text to a wikilink, or split scalar text into a YAML list using a literal delimiter. Rename and merge remove equal duplicates in changed lists.

Every operation shows a complete list of affected paths and before/after values, and requires explicit Apply confirmation. Matching values are edited across the vault, regardless of tree search or saved views. Notes whose property changes after preview are skipped, and write failures are reported individually.

## Undo and the new write behavior

Browsing remains read-only. This is the first release with explicit actions that write to notes. Obsidian's frontmatter writer may change YAML formatting, comments, or quoting; note bodies are not edited.

Use **Supercharged Properties: Undo last value edit** to restore the previous property values in the last successful batch. Undo preserves later changes by skipping conflicting values. Failed or skipped entries can be retried. Undo is held in memory: another successful batch replaces it, and restarting or disabling the plugin clears it. It restores values, not original YAML formatting. Renamed or deleted notes cannot be restored through their old paths.

Merging multiple source values requires separate batches. Undo covers only the most recent successful batch.

## Installation

For manual installation, copy the attached `main.js`, `manifest.json`, and `styles.css` into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then reload and enable the plugin. Desktop and mobile are supported; the core Search plugin is needed only for Open in Search.
