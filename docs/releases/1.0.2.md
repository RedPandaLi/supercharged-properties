# Supercharged Properties 1.0.2

Released 2026-11-14.

This patch improves the failure path for **Open in Search**.

## Fixed

- **Open in Search** now removes the temporary pane it creates when the Search view cannot be opened.
- If the core Search plugin is unavailable, the action shows **“Enable the Search core plugin to use Open in Search.”** instead of leaving an empty pane behind.
- Existing Search panes are still reused, and the property tree remains fully usable when Search cannot be opened.

Everything else is unchanged: the property tree, typed values, search, property scopes, saved views, sorting, pinning, hiding, and the other row actions work as before.

## Installation

1. Open **Settings → Community plugins → Browse** and install **Supercharged Properties** if it is listed.
2. To install manually, copy `main.js`, `manifest.json`, and `styles.css` into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then enable the plugin.

Requires Obsidian 1.7.2 or later. The core Search plugin is needed only for **Open in Search**.
