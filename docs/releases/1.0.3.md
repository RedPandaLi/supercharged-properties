# Supercharged Properties 1.0.3

Released 2026-11-14.

This release restores property type icons using public Obsidian APIs only.

## Added

- **Property type icons** appear before each property name in the tree.
- Icons come from the type configured in Obsidian, such as text, list, tags, number, checkbox, date, and date & time.
- Types are read from `.obsidian/types.json` through the public `vault.adapter` API.
- When a type is not configured, the built-in `tags`, `aliases`, and `cssclasses` names are recognized, and everything else falls back to text.

## Changed

- **Refresh property index** also reloads configured property types, so icon changes appear after a refresh.
- The plugin description mentions property type icons again.
- No private Obsidian APIs such as `metadataTypeManager` or `registeredTypeWidgets` are used.

Everything else is unchanged: the property tree, typed values, search, property scopes, saved views, sorting, pinning, hiding, and native Search actions all work as before. The plugin remains read-only.

## Installation

1. Open **Settings → Community plugins → Browse** and install **Supercharged Properties** if it is listed.
2. To install manually, copy `main.js`, `manifest.json`, and `styles.css` into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then enable the plugin.

Requires Obsidian 1.7.2 or later. The core Search plugin is needed only for **Open in Search**.
