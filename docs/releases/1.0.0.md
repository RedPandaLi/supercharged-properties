# Supercharged Properties 1.0.0

Released 2026-11-14.

The first public release of Supercharged Properties turns YAML frontmatter into a full-pane, read-only tree of properties, values, and notes.

## Highlights

- **Explore metadata visually** — expand any property to see its values, then expand a value to see every note that uses it.
- **Search with context** — search property names, values, note names, or paths; matching branches open automatically.
- **Save focused views** — pick the properties you care about and save the selection as a named view.
- **Stay in control of the tree** — sort by name or frequency, pin important properties, and hide noisy ones.

## Features

- Incremental index built from Obsidian's metadata cache, with live updates for edits, creates, deletes, renames, metadata resolution, and type changes.
- Typed value rows for strings, numbers, booleans, empty values, and nested lists, with per-note deduplication and cycle protection.
- Type icons driven by Obsidian's configured property types, with a text fallback and no inference from note contents.
- Search scopes for everything, property names, values, and note names/paths.
- Property picker with All / None shortcuts, filtering, and live counts.
- Saved views (profiles) with create, update, rename, and delete actions.
- Sort modes for property name (A–Z and Z–A) and distinct-note frequency (high and low).
- Pin and hide actions, plus hidden-property management in settings.
- Native Obsidian Search integration, with copy actions for property queries and matching note links.
- Accessible controls with labelled buttons, keyboard-operable context menus, focus restoration, and a live summary.
- Settings for note counts, sort order, and hidden properties.

## Installation

1. Open **Settings → Community plugins → Browse** and install **Supercharged Properties** if it is listed.
2. To install manually, copy `main.js`, `manifest.json`, and `styles.css` into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then enable the plugin.

Requires Obsidian 1.7.2 or later. The core Search plugin is needed only for **Open in Search**.

## Notes and limitations

- The plugin is read-only and never modifies notes.
- Unsupported object values do not produce value rows, but their notes remain visible under the property.
- Empty-value search uses Obsidian's `null` operator; the local empty row also includes blank strings and empty lists.
- Property type icons follow Obsidian's configured types. Types are not inferred from note contents.
